# KoHs Crystal Tweaks 2.0.4 — Minecraft 1.21.2–1.21.4

Stable safety release for Fabric and Java 21.

Artifact: `kohs-crystal-tweaks-2.0.4+mc1.21.2.jar`

## Safety changes

- Removed custom client-identification and compatibility payloads.
- Removed sub-tick, delayed, replayed, and automatically retried actions.
- Removed automatic hotbar-slot changes.
- One physical attack or use input can produce at most one corresponding vanilla action.
- The optional visual crystal preview is render-only, non-targetable, and OFF by default.
- Optional local cleanup requires the exact real, server-provided crystal targeted by the player's normal attack and is OFF by default.

Visual, sound, and manual safety controls remain available. The server remains authoritative.

No universal anti-cheat guarantee is claimed; check the rules of the server before using any client mod.
